Hi! I'm Morgan, a mobile software engineer working on credit products with Flutter, Kotlin and Swift, and a master's student researching NoSQL schema design.

For a long time my notes lived scattered across repositories, papers and half-finished drafts. This blog is where I'll put them in order: what I'm studying, what I'm building, and what I learn along the way.

## What you'll find here

- **Mobile engineering** — Flutter, Kotlin and Swift in real products, architecture and testing.
- **Research** — notes from my master's work on document-oriented databases and schema selection.
- **Studies** — anything else I'm learning and think is worth writing down.

## How this site is built

The site runs on [Astro](https://astro.build) and is hosted on [Cloudflare Workers](https://workers.cloudflare.com). I chose Astro because it's made for content: each post is just a Markdown file in the repository, pages ship almost no JavaScript, and publishing is a `git push` away.
